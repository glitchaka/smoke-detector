# ROMs locales

Esta carpeta es la biblioteca local de ROMs de `promptemon-steidium`.

Puedes colocar varias ROM a la vez. El cargador recorre la carpeta y subcarpetas, identifica GB/GBC/GBA/NDS/CIA/3DS/CCI/CXI y combina en el visor los modelos 3D encontrados en fuentes compatibles.

Las ROM de GB/GBC/GBA/NDS se reconocen como fuentes de datos, pero no se inventan modelos 3D que esas ROM no contienen. Las fuentes 3DS con RomFS legible y recursos BCH pueden aportar modelos al selector.

No subas ROMs comerciales al repositorio público. Déjalas sólo en tu copia local dentro de esta carpeta.
